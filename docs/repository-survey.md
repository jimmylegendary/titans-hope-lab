# 공개 Titans·Nested Learning 저장소 조사

**조사 스냅샷:** 2026-10-20. 아래는 GitHub 검색 결과와 공개 코드에서 선별한 구현의 조사 기록이며, GitHub 전체 저장소를 빠짐없이 열거했다는 뜻은 아닙니다. 논문 ID·정확한 제목·저자·keywords와 변형 이름을 조합해 검색하고, README와 핵심 source/tree를 확인했습니다. 검색 API 일부는 HTTP 403을 반환했고 검색 결과 페이지·페이지 수에도 한계가 있습니다. 대부분의 외부 후보는 정적 코드 검토이며 이 저장소에서 실행하지 않았습니다.

## 검색 결과를 읽는 기준

Titans는 논문 ID `2501.00663`, 정확한 제목, Titans/neural memory/PyTorch, MAC/MAG/MAL 및 저자 계열 검색을 사용했습니다. 초기 선별 약 70개와 더 넓은 검색에서 모은 235개 후보 집합은 각각 검색 작업의 후보 수이지, 독립 구현 수나 완전한 모집단이 아닙니다. HOPE/Nested Learning은 논문 ID `2512.24695`, 제목, 저자, Nested Learning/HOPE/CMS/SMT/M3/DMGD 키워드를 조합했습니다. 초기 후보 기록은 직접 구현 15개, 인접 2개, 키워드 오탐 7개를 구분했습니다. 후속 source audit는 Lazarus-931/Nested_Learning을 직접 후보로, Abraheem13/HOPE-PHY를 인접 후보로 추가했습니다. README 주장은 코드로 확인한 사실과 아래 표에서 구별합니다.

표의 `정적 확인`은 source에서 update rule이나 상태 경계를 읽었다는 뜻입니다. 테스트 함수나 committed artifact가 있다는 표시는 존재 여부만 가리킵니다. 직접 실행된 외부 프로젝트라는 의미가 아닙니다. 공개 root의 이 두 runtime snapshot에 대한 실제 CPU 검증은 별도 [validation.md](https://github.com/jimmylegendary/titans-hope-lab/blob/main/docs/validation.md)에 있습니다.
